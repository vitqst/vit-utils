# Execution Plans

Use `docs/exec-plans/active/` for work in progress and `docs/exec-plans/completed/` for verified work.

An execution plan contains:

- a measurable goal;
- architecture and scope;
- exact files;
- test-first implementation steps;
- verification commands;
- explicit deferred work.

Update the active plan when the approach changes. After tests, type-check, build, and relevant browser checks pass, record the evidence and move the file to `completed/`.

# Product Sense

## Promise

Open the page, complete one practical task, and leave without creating an account or surrendering data.

## Prioritization

Prefer tools that:

1. solve a repeated, well-defined job;
2. work fully in the browser;
3. benefit from offline access;
4. are easy to explain and verify;
5. add meaningful Vietnamese-language utility.

Avoid shipping a thin wrapper around an online API when a local implementation is practical. If a network call is intrinsic—such as a k-anonymity breach lookup—the tool must disclose exactly what is sent and remain isolated from unrelated user data.

## Success signals

The platform has no behavioral analytics by design. Evaluate quality through opt-in feedback, repository issues, search visibility, performance budgets, and reproducible acceptance tests.

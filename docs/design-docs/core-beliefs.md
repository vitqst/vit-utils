# Core Beliefs

1. **The browser is the product boundary.** User data stays in the active browser unless a tool clearly documents an intentional, privacy-preserving exception.
2. **One tool, one job.** A tool should be understandable from its name, description, and first screen.
3. **Privacy must be inspectable.** Claims are reinforced by same-origin CSP, no trackers, no remote fonts, and visible local-only badges.
4. **Fast before clever.** The shell stays small; tool code and large libraries load only when requested.
5. **Offline is normal.** A previously opened tool should remain useful without a connection.
6. **English and Vietnamese are peers.** New shell and registry copy ships in both languages.
7. **Accessibility is behavior.** Keyboard access, focus, labels, contrast, and reduced ambiguity are tested like any other feature.
8. **The registry is the catalog.** Discovery surfaces must not maintain private lists of tools.

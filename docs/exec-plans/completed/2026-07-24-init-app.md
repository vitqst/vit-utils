# Init App Implementation Plan

**Goal:** Turn the existing Photo Cure prototype into the first lazy-loaded tool in a private, offline-first, bilingual browser-tool platform.

**Architecture:** A React and TypeScript application shell reads every visible tool and route from one typed registry. Tool modules load through `React.lazy`, while shared shell concerns—navigation, search, favorites, recents, locale, privacy messaging, and PWA registration—remain independent from tool code. The existing Photo Cure implementation moves under `src/tools/photo-cure/` and keeps its behavior tests.

**Tech stack:** React 19, Vite 7, TypeScript, SWC, Tailwind CSS, Headless UI, Radix UI, Vitest, Testing Library, and Firebase Hosting.

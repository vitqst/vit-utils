# Meta Tags & Open Graph Preview

## Purpose

Build escaped HTML metadata and preview its textual social-card layout locally.

## Behavior

- Configure title, description, canonical URL, site name, content type, locale,
  image URL, robots, and Twitter card type.
- Validate optional URLs as absolute HTTP/HTTPS values.
- Escape every HTML text/attribute value and generate deterministic title,
  standard meta, canonical, Open Graph, and Twitter tags.
- Show title/description character counts and non-blocking recommended-length
  guidance.
- Show a local social-card mockup using text and the image URL label only. The
  preview must not fetch the remote image.
- Copy or download the generated snippet.

## Accessibility and localization

- Every field, preview region, guidance, output, and action is semantic.
- English and Vietnamese copy ship together.

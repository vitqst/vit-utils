
This website is a collection of small, single-purpose tools that run entirely in the browser. No uploads, no tracking, no ads. Just open the page and use the tool.

The strongest is we will use firebase hosting to deploy the website, your data will never leave your browser, and we will not track you. The website is open source, and you can even run it locally if you want

## Requirements worth locking in now

These shape the architecture, so decide them before the first tool:

1. **Tool registry, not hand-written routes** — every tool is a self-describing module: `{ id, group, name, keywords, icon, load: () => import(...) }`. Sidebar, group switcher, search, and sitemap all read from it. Adding a tool = adding one file.
2. **Lazy load per tool** — don't ship ffmpeg.wasm to someone who wants base64.
3. **Web Workers for anything heavy** — image/video/hashing on large files must not freeze the UI.
4. **Cmd+K palette + favorites/recent** — past ~50 tools, browsing by group gets slow.
5. **Offline PWA** — reinforces the no-upload promise and survives bad connections.
6. **One static page per tool (SSG)** — this is where organic traffic comes from; each group gets a hub page.
7. **i18n vi/en from day one** — retrofitting is painful, and the VN tools need it.
8. **Verifiable privacy** — zero outbound requests on tool pages, so a skeptical user can open DevTools and confirm it. Put a badge on each tool.
